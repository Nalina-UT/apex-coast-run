# APEX — Coast Run 🏎️

A browser-based 3D racing game built with HTML, CSS, JavaScript, and Three.js.

## 🎮 Live Demo

[Play APEX — Coast Run](https://nalina-ut.github.io/Apex-racing/)

Click **Start Your Engine** to begin.

## Features

- Detailed Ferrari 458 Italia cars
- Textured 3D trees and a photographic landscape
- Three-lap races against three AI opponents
- Nitro boost and drifting
- Three camera views and engine sound
- Keyboard and touch controls
- Collision elimination: hitting another car ends your race

## Controls

| Key | Action |
| --- | --- |
| W / ↑ | Accelerate |
| S / ↓ | Brake |
| A / ← | Steer left |
| D / → | Steer right |
| Space | Nitro boost |
| Shift | Drift |
| C | Change camera |
| P | Pause / resume |
| R | Restart race |

## Run Locally

1. Download this repository and extract it.
2. Open the folder in Visual Studio Code.
3. Install the **Live Server** extension by Ritwick Dey.
4. Right-click `index.html` and select **Open with Live Server**.

Use a local web server instead of opening `index.html` directly, so the 3D models load correctly.
